Abstract

Foundation models and large-scale human data provide rich sources of manipulation intent, but translating this intent into multi-fingered robot motion remains difficult. A key bottleneck is the lack of general-purpose low-level skills for dexterous hands, which must coordinate high-dimensional actions and establish reliable contact across tasks and embodiments. In this paper, we propose General Object Trajectory Tracking (GOTT), a framework that uses the object trajectory as a robot-agnostic interface for dexterous manipulation. Given a rigid object mesh and a desired object motion, GOTT converts it into executable robot behavior through three stages: future-aware motion planning, learned contact acquisition, and object-pose-conditioned end-effector tracking. This decomposition allows the system to reason about long-horizon kinematic feasibility while using a unified contact acquisition controller to handle the contact-rich transition from init grasp to stable grasp. We evaluate GOTT in simulation and real-world experiments across multiple hands, objects, and tasks. We show that GOTT can execute diverse dexterous manipulation behaviors, including object picking across hand embodiments, tool use, pouring, whiteboard erasing, and trash cleanup.

Reward Design

The per-step reward used to train the contact-acquisition controller is: (click each term for more details!)

\[ r \;=\; \class{rw-term rw-dist}{\underbrace{w_d\,r_{\mathrm{dist}}}_{\textstyle\text{distance}}} \;+\; \class{rw-term rw-contact}{\underbrace{w_c\,r_{\mathrm{contact}}}_{\textstyle\text{contact}}} \;+\; \class{rw-term rw-lift}{\underbrace{w_l\,r_{\mathrm{lift}}}_{\textstyle\text{lifting}}} \;+\; \class{rw-term rw-obj}{\underbrace{w_o^{p}\,r^{p}_{\mathrm{obj}} + w_o^{r}\,r^{r}_{\mathrm{obj}}}_{\textstyle\text{object stability}}}, \]

where all rotation distances $\Delta\theta$ are the geodesic quaternion angle $\Delta\theta = 2\arccos(|\langle q_1, q_2\rangle|)$. Reward weights are listed in the table below.

Distance reward $r_{\mathrm{dist}}$. A negative weighted sum of per-link link-to-surface distances, each clipped at $0.1$ m:

\[ r_{\mathrm{dist}} = -\sum_{l} \omega_l \, \min\!\big(\lVert \mathbf{a}_l \rVert,\, 0.1\big), \]

with per-link weights assigned in raw form as $\omega_{\text{thumb-tip}} = 8$, $\omega_{\text{other fingertips}} = 4$, $\omega_{\text{palm}} = 0$, and $\omega_l = 1$ for all remaining links, then normalised to sum to $1$ over the active links. In cross-embodiment the weights are masked to active links and re-normalised per environment. The link-to-surface distance $\lVert \mathbf{a}_l \rVert$ is defined as follows: for each canonical link $l$ at world position $\mathbf{p}_l$, $\mathbf{a}_l$ is the vector to its nearest point on the object's surface point cloud (the $\arg\min$ over $M = 512$ sampled points), and $\lVert \mathbf{a}_l \rVert$ is the $L2$ norm. The point cloud is stored object-local and transformed to world with the tracked object pose.

Contact reward $r_{\mathrm{contact}}$. Encourages both thumb contact and an opposing grasp, in which the thumb and at least one non-thumb finger simultaneously contact the object:

\[ r_{\mathrm{contact}} = \mathbf{1}[\text{thumb in contact}] + \mathbf{1}[\text{is_grasping}], \]

where a finger is considered to be “in contact” if its contact force with the object exceeds a threshold $\epsilon_{\mathrm{contact}} = 0.05$ N, and $\text{is_grasping} = (\text{thumb in contact}) \wedge (\exists\,\text{non-thumb in contact})$.

Lifting reward $r_{\mathrm{lift}}$. A grasp-gated, scaled reward proportional to the object's height above its post-reset position:

\[ r_{\mathrm{lift}} = \mathbf{1}[\text{is_grasping}] \cdot \mathrm{clip}\!\big(100\,\Delta h,\ 0,\ 100\,h_{\mathrm{thr}}\big), \quad \Delta h = \max(0,\ z - z_0), \]

where $z$ is the object's current height, $z_0$ is its height immediately after reset, and $h_{\mathrm{thr}} = 0.05$ m (so the clip ceiling is $5.0$). The reward is gated by $\mathbf{1}[\text{is\_grasping}]$, ensuring that the policy only earns lifting reward once the object is actually grasped, and is clipped to prevent runaway reward when the object is thrown upward.

Object stability reward $r_{\mathrm{obj}}$. Exponential “stay-put” bonuses on planar displacement and rotation from the post-reset pose:

\[ r^{p}_{\mathrm{obj}} = e^{-10\,\lVert \Delta \mathbf{xy} \rVert}, \qquad r^{r}_{\mathrm{obj}} = e^{-\Delta\theta(\mathbf{q}, \mathbf{q}_0)}, \]

where $\Delta \mathbf{xy} \in \mathbb{R}^2$ is the planar displacement between the object's current $xy$ position and its post-reset position, and $\Delta\theta(\mathbf{q}, \mathbf{q}_0)$ is the rotation angle between the object's current orientation $\mathbf{q}$ and its post-reset orientation $\mathbf{q}_0$. These rewards discourage the policy from sliding or rotating the object during the contact-acquisition phase, which we found is important for stable real-world execution.

Curriculum / annealing. The object-stability weights are linearly annealed from an initial value to the final value over $T_{\mathrm{cur}}$ per-environment control steps: $w(t) = w_{\mathrm{init}}(1 - \rho) + w_{\mathrm{final}}\,\rho$, $\rho = \min(1,\ t / T_{\mathrm{cur}})$. We anneal $w_o^{p}, w_o^{r}$ from $w_{\mathrm{init}} = 2.0$ to $w_{\mathrm{final}} = 10.0$ over $T_{\mathrm{cur}} = 10^5$ steps. The distance, contact, and lifting weights are not annealed.

Symbol Term Value
$w_d$ distance $16.0$
$w_c$ contact $4.0$
$w_o^{p}$ object position stability $10.0$ (init. $2.0$)
$w_o^{r}$ object rotation stability $10.0$ (init. $2.0$)
$w_l$ lifting $1.0$
